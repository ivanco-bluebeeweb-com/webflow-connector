# Webflow Connector — что видит и чем управляет пользователь после подключения

## 1. Целевой пользователь
Маркетолог/веб-дизайнер малого-среднего бизнеса, использующий Webflow как no-code
конструктор сайта с CMS (часто вместо WordPress — за визуальный контроль без кода).

## 2. Момент истины после подключения
Сразу после `connect_webflow` — список сайтов воркспейса (`list_sites`) с доменами и
статусом публикации, плюс `list_collections` — какие CMS-коллекции (блог, товары,
кейсы) уже настроены.

## 3. Что пользователь видит
- Сайты воркспейса и их домены/статус публикации — `list_sites`, `get_site`.
- CMS-коллекции и их поля (реальная схема, которую сам клиент настроил) —
  `list_collections`, `get_collection_schema`.
- Элементы коллекции (записи блога, товары и т.д.) — `list_collection_items`.
- Формы сайта и их отправки (лиды) — `list_forms`, `list_form_submissions`.
- Активы (загруженные изображения/файлы) — `list_assets`.
- Настройки e-commerce (заказы, товары), если включён Webflow Ecommerce —
  `list_ecommerce_orders`, `list_ecommerce_products`.
- Вебхуки, настроенные для сайта — `list_webhooks`.

## 4. Чем пользователь может управлять
- Создавать/обновлять/удалять элемент CMS-коллекции — `create_collection_item`,
  `update_collection_item`, `delete_collection_item`.
- Публиковать сайт на домен (production) — `publish_site`.
- Загружать новый актив (изображение) — `upload_asset`.
- Обрабатывать заказ e-commerce (менять статус, фулфилмент) — `update_order_status`.
- Создавать вебхук для реагирования на события сайта в реальном времени —
  `create_webhook`.

## 5. "Вау"-момент для демо потенциальному клиенту
"Смотри — говорю Webbee: 'добавь новую запись в блог с этим текстом и опубликуй сайт'.
Она создаёт элемент через `create_collection_item` в РЕАЛЬНОЙ схеме полей клиента и
публикует через `publish_site` — без открытия Webflow Designer."

## 6. Что делает это "заточенным под него"
`get_collection_schema` читает точную структуру полей, которую клиент сам придумал для
своего сайта (не универсальный шаблон блога) — Webbee работает с его реальным контентом.
