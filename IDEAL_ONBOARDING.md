# Webflow Connector — идеальный первый запуск

Источник: `ONBOARDING_FIRST_LAUNCH_STANDARD.md`. Целевой пользователь: маркетолог/
веб-дизайнер SMB на Webflow.

## 1. Credential type
API key (Site Token ИЛИ Workspace Token — два разных класса подключения с разным
охватом, оба статические ключи).

## 2. Идеальный флоу
1. **Первое открытие** — `Empty` с явным выбором ДО формы: "Подключить один сайт
   (Site Token) или всю рабочую область (Workspace Token)?" — идеально в виде
   `Tabs`/двух явных карточек-опций с описанием разницы, а не единая форма с двумя
   полями, где непонятно какое заполнять.
2. **Site Token форма** — ссылка "Site Settings > Apps & integrations > API access" +
   поле token + опциональный label.
3. **Workspace Token форма** — предупреждение "видно только чтение, все сайты
   workspace" (read-only ограничение, судя по описанию поля) — явно, не мелким шрифтом.
4. **После успеха** — `list_sites` + `list_collections` сразу — домены, статус
   публикации, CMS-коллекции, без доп. клика.
5. **Multi-site** — если Workspace Token — сразу список всех сайтов с быстрым
   переключением активного для последующих действий.
6. **Ошибка "token scope mismatch"** — если Site Token используется там, где нужен
   Workspace-охват (или наоборот) — конкретное объяснение разницы, а не общая ошибка
   авторизации.
